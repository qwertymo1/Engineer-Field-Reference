# Engineer Field Reference

Offline-capable field guide to engineering and survivability tasks for 12Ns,
built from Army doctrine and technical manuals. Installs to a phone's home
screen and works without signal.

## How it updates
Push a change to this repo (edit `content.json` or a file under `images/`,
commit, push). GitHub Pages republishes automatically, and installed phones
pick up the new version the next time they have signal.

## Files
- `index.html` - app shell (loads the content, registers the service worker)
- `app.js` - the application logic (navigation, search, backup, viewers)
- `content.json` - all tasks, sections, glossary, and the image index
- `images/` - figures from the source manuals
- `sw.js` - service worker (offline caching + self-update)
- `manifest.webmanifest`, `icons/` - install metadata and app icons

Generated by pwa_gen.py - do not hand-edit generated files; change the source.
